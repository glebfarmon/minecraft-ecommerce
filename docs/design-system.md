## 2. Типографика

### Шрифты

Оригинал hero набран платным гротеском (похож на Helvetica Now Display / Neue Montreal). Бесплатная замена с latin-ext (нужен для польских диакритик `ą ć ę ł ń ó ś ź ż`). Языки сайта только EN/PL, кириллица не подключается:

| Роль | Шрифт | Почему |
|---|---|---|
| `--font-sans` — всё: заголовки, текст, UI | **Inter Tight** (Google Fonts, 400 / 500 / 700 / 800) | Самый близкий по форме к hero, плотный по ширине, полный latin-ext |
| `--font-display` — слово-фон сервера, цены | **Oswald** (600 / 700) | Узкий и тяжёлый, как `RISE` / `BOLD` в planet; есть latin-ext |
| `--font-mono` — IP сервера, хеши на `/fairness` | **JetBrains Mono** (500) | Моноширинный нужен для хешей и сидов |

Подключение через `next/font/google`, `subsets: ['latin', 'latin-ext']`, `display: 'swap'`.

### Шкала

Fluid-размеры (`clamp`), база 16px.

| Токен | Размер | Начертание | Межстрочный | Трекинг | Где |
|---|---|---|---|---|---|
| `text-hero` | `clamp(4rem, 11vw, 10rem)` | 700 | 0.88 | -0.045em | `your - new` / `second - home` (PL: `twój - nowy` / `drugi - dom`) |
| `text-display` | `clamp(6rem, 20vw, 18rem)` | Oswald 700, капс | 0.85 | -0.01em | Слово-фон сервера за персонажем/товаром |
| `text-h1` | `clamp(2.5rem, 5vw, 4rem)` | 700 | 0.95 | -0.03em | Название сервера в левой колонке |
| `text-h2` | `2rem` | 700 | 1.05 | -0.02em | Заголовки секций |
| `text-h3` | `1.375rem` | 500 | 1.2 | -0.01em | Название товара в карточке |
| `text-price` | `2rem` | Oswald 600 | 1 | 0 | Цена в карточке |
| `text-body` | `1rem` | 400 | 1.5 | 0 | Абзацы (макс. 38ch, как в hero) |
| `text-small` | `0.875rem` | 400 | 1.4 | 0 | Категория в карточке, подписи |
| `text-label` | `0.8125rem` | 500, капс | 1.2 | 0.02em | `//JOIN US`, `//NEW SEASON`, `/ Version 1.20+` |
| `text-nav` | `0.8125rem` | 600, капс | 1 | 0.14em | Ссылки navbar, заголовки групп в дропдауне (`LANGUAGE`, `CURRENCY`) |

### Правила

1. Hero-заголовок всегда в нижнем регистре, вторая строка начинается с `- ` и сдвинута на одну колонку.
2. Метки начинаются с `//` (основные) или `/` (вторичные). Всегда капс, всегда у линии сетки или в углу.
3. Капс + широкий трекинг только у навигации и групповых заголовков. В остальных местах капс с трекингом не используется.
4. Не больше трёх размеров на один блок.

| `--color-line` | `rgb(255 255 255 / 0.07)` | Направляющие сетки, разделители |
| `--color-border` | `rgb(255 255 255 / 0.12)` | Рамки пилюль (язык/валюта, IP) |
| `--color-fg` | `#F2F2F2` | Основной текст |
| `--color-fg-muted` | `#8E8E93` | Неактивные пункты меню, вторичный текст |

| `--color-danger` | `#FF4D4F` | Ошибки форм |

### Акцент сервера

Каждый сервер задаёт два значения: `accent` и `on-accent` (цвет текста поверх акцента). Они кладутся в CSS-переменные на `<main data-server="…">`, и все акцентные элементы читают их оттуда.

| Сервер (пример) | `--accent` | `--on-accent` | Контраст текста |
|---|---|---|---|
| Survival (по умолчанию, оранжевый из hero) | `#FF6B1A` | `#0E0E10` | 6.8 : 1 |
| Anarchy (фиолетовый из planet) | `#7B3FF2` | `#FFFFFF` | 5.5 : 1 |
| Minigames (малиновый из planet) | `#D92B52` | `#FFFFFF` | 4.8 : 1 |

Правила акцента:

1. Акцент занимает не больше ~10% экрана: CTA-кнопка, активный чип/категория, знак-декор, свечение за персонажем.
2. Зелёный нельзя брать в акцент сервера: он занят онлайн-индикатором.
3. Новый сервер в админке — новый цвет проверяется на контраст `on-accent` ≥ 4.5 : 1.
4. Производные: `--accent-soft: color-mix(in oklab, var(--accent) 18%, transparent)` для фонов чипов и свечения; `--accent-hover: color-mix(in oklab, var(--accent) 88%, white)`.

## 6. Компоненты

### Navbar (navbar-2/3 + `navbar.txt`)
- Плавающая пилюля `--color-surface`, рамка `--color-border`, отступ сверху 16px, высота 64px, `backdrop-filter: blur(12px)` поверх фона.
- Слева лого. По центру: Home, Donate Cases, Rules, Contacts (`text-nav`, `--color-fg-muted`, активный — `--color-fg`).
- Справа: онлайн (точка `--color-online` + число), пилюля язык/валюта (`EN · €`), корзина (иконка + счётчик на `--accent`).
- Дропдаун язык/валюта — как navbar-3: группы `LANGUAGE` / `CURRENCY` (EN / PL и EUR / PLN), пункт с кодом слева и галочкой справа, выбранный — фон `rgb(255 255 255 / 0.06)`.
- Mobile: лого + онлайн + корзина + бургер, меню на весь экран.

### Hero (hero.png + hero-steve.webp + `hero.txt`)
- Тёмный фон, видимые направляющие. По центру `hero-steve.webp`, нижний край уходит за экран.
- Заголовок разбит вокруг персонажа: слева `your` / `- new`, справа `second` / `- home` (`text-hero`). Тексты — в разделе 7.
- Метки: `//JOIN US` слева посередине, `//NEW SEASON` справа сверху, `/ Version 1.20+` слева снизу.
- Абзац `text-body` max 38ch в колонках 2–4 снизу.
- Справа снизу вместо `280K`: блок онлайна — `67` (`text-h1`) + мигающая точка `--color-online`, под ним кнопка IP.
- 1–2 знака-декора акцентом (`+`, цветок) — не больше.

### Индикатор онлайна
- Точка 8px `--color-online` + кольцо, которое расширяется и гаснет: `scale 1→2.4`, `opacity .6→0`, 1.6s, бесконечно.
- `aria-label="Server online, 67 players"`. Если сервер офлайн — точка `--color-fg-muted`, без анимации, текст `Offline`.

### Кнопка IP (copy-ip.png)
- Пилюля, рамка `--color-border`, высота 48px, padding 0 24px. Текст `font-mono` 500, капс. Иконка копирования справа.
- Клик — копирует, иконка на 1.5s меняется на галочку, `aria-live="polite"` сообщает `IP copied`.

### Переключатель серверов
- Над сеткой: `‹` + пилюли серверов + `›`. Активная пилюля — фон `--accent`, текст `--on-accent`; остальные — рамка `--color-border`.

### Категории (правая колонка)
- Вертикальный список пилюль на всю ширину колонки, высота 48px. Активная — фон `--accent-soft`, текст `--color-fg`, слева точка `--accent`. Если категорий > 6 — внизу `⌄` разворачивает остальные.

### Карточка товара (product-card.png, без «избранного», выше)
- Рамка `--color-card`, `--radius-card`, padding 8px, соотношение сторон ≈ 3 : 4.6 (выше оригинала 3 : 4.3).
- Сверху плитка `--color-card-media`, `--radius-inner`, aspect 1 : 1, рендер товара по центру.
- Ниже (padding 16px): название `text-h3`, одна строка с многоточием; категория `text-small` `--color-fg-muted`.
- Низ: цена `text-price` слева, квадратная кнопка 56×56 `--radius-inner` справа — белая с тёмной иконкой корзины; hover — фон `--accent`, иконка `--on-accent`.
- Hover карточки: плитка `scale(1.03)` у картинки, 300ms. Бейдж `18+` у кейсов — пилюля в правом верхнем углу плитки.

### Кнопки
| Вариант | Вид |
|---|---|
| Primary | Пилюля `--accent` / `--on-accent`, 48px, 600 |
| Secondary | Пилюля белая `#F2F2F2` / `--color-fg-inverse` |
| Ghost | Пилюля с рамкой `--color-border`, текст `--color-fg` |
| Icon | Круг 44px, как иконки поиска/корзины в hero |

Минимальная зона клика 44×44. Фокус: `outline: 2px solid var(--accent); outline-offset: 3px`.

### Футер
- 4 полосы на всю ширину, разделены `--color-line`: (1) крупный лого + слово-фон сервера `text-display` с низкой непрозрачностью; (2) 3–4 колонки ссылок: Shop / Help / Legal / Community; (3) IP + онлайн + язык/валюта; (4) копирайт и плашка «demo, Stripe test mode».
- Заголовки колонок — `text-label` с `//`.

## 8. Движение

Библиотека — Motion. Общая кривая `--ease-out: cubic-bezier(0.22, 1, 0.36, 1)`.

| Токен | Длительность | Где |
|---|---|---|
| `--dur-fast` | 150ms | Hover, нажатие |
| `--dur-base` | 300ms | Дропдауны, смена категории |
| `--dur-slow` | 700ms | Смена сервера |

### Смена сервера (server-change-1…5)

Кадры рефа: старый объект уезжает вверх, фон перекрашивается целиком, новое слово-фон поднимается снизу, новый объект падает сверху и чуть доворачивается. Перенос на наш экран:

1. **0–250ms** — текущие карточки и персонаж уходят вверх (`y: -40`, `opacity: 0`), слово-фон уходит вниз.
2. **0–700ms** — `--accent` плавно переходит в цвет нового сервера (CSS `@property --accent` с `syntax: '<color>'`, `transition: --accent 700ms`). Перекрашиваются кнопки, активные чипы, свечение за персонажем, мигание не трогается.
3. **250–600ms** — новое слово-фон (`text-display`, название сервера) поднимается снизу (`y: 80 → 0`).
4. **300–700ms** — название и описание слева меняются через `opacity` + `y: 12 → 0`; карточки появляются каскадом по 40ms, `y: 24 → 0`, `rotate: -2° → 0`.
5. Фокус клавиатуры остаётся на пилюле сервера.

`prefers-reduced-motion: reduce` — только crossfade 200ms, без сдвигов и поворотов, мигание точки онлайна статично.

```css
}
```

Цвета серверов приходят из API (поле сервера `accent` / `onAccent`) и ставятся inline: `<main data-server="survival" style={{ '--accent': s.accent, '--on-accent': s.onAccent }}>`.

---

## 10. Чего не делаем

1. Второй акцентный цвет на одном экране.
2. Градиенты на кнопках (в navbar-рефе есть, но они спорят с плоским hero).
3. Пиксельные «майнкрафтовые» шрифты: тема Minecraft передаётся через рендеры (Steve), а интерфейс остаётся чистым гротеском.
4. Тени у карточек: глубину даёт контраст светлой плитки и тёмной рамки.
5. Капс с трекингом вне навигации и групповых заголовков.
