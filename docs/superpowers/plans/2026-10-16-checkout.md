# Checkout and Payments (4a) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A player pays for the cart with Stripe (test mode) or the e2e fake gateway, lands on `/order/{publicId}` that says paid, gets a receipt email; support sees the order in admin `/orders`.

**Architecture:** New NestJS `orders` module (public create/read, Stripe webhook, admin read) behind a `PaymentsGateway` seam (`StripeGateway`, `FakeGateway`); Prisma tables `orders`, `order_items`, `processed_webhook_events`; contract in `@shop/shared/orders`. Web submits the checkout form to `POST /api/orders` on its own origin with a Turnstile token and redirects to the gateway; a new status page polls the order. Admin gets a read-only orders list and order page through RTK Query codegen.

**Tech Stack:** NestJS 11, Prisma 7 (adapter-pg), Stripe Node SDK (`stripe`), Cloudflare Turnstile (`@marsidev/react-turnstile` on web), Valibot, React Email, Next.js 16 + next-intl, RTK Query codegen, Playwright, Jest + Testcontainers.

**Spec:** `docs/superpowers/specs/2026-10-16-checkout-design.md` (parent: `docs/superpowers/specs/2026-10-01-minecraft-donation-shop-design.md` §9.1)

## Global Constraints

- Business logic only in `apps/api`; Next.js apps have no route handlers. NestJS global prefix `/api`.
- Money is `amountMinor: Int` + `currency` (`EUR` | `PLN`). Never floats.
- Do not bump ESLint (9) or TypeScript (6) majors.
- Admin endpoints use `@AdminController(path)` + `@RequirePermission(...)`; public endpoints `@AllowAnonymous()`. Every route documented in `apps/api/src/openapi/` with `operationId`, `tags`, `summary`, `description`, response descriptions (`admin-routes.spec.ts` enforces admin ones). Regenerate `apps/api/openapi.json` (`pnpm --filter @shop/api openapi`) and admin codegen (`pnpm --filter @shop/admin codegen`) after API contract changes.
- Error bodies `{statusCode, message, issues?}` via `apps/api/src/common/http-errors.ts`; `message` is a stable code.
- Frontend layout: `app/` + `_components`, `features/<name>/`, `components/`, `lib/`, `config/` (ADR 0004/0005); no barrels. Storefront texts in `packages/messages/en.json` and `pl.json` (both, same keys).
- TDD: failing test first. Unit tests `*.spec.ts` (api) / `*.test.ts(x)` (web, admin) stay DB-free; Postgres tests are `apps/api/test/*.int-spec.ts`.
- Gate before every commit: `pnpm format:check && pnpm lint && pnpm typecheck && pnpm test` (+ `pnpm --filter @shop/api test:int` for tasks touching the DB).
- Conventional Commits; trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Never commit secrets; new env vars go to `.env.example`. e2e-only throwaway values are allowed in `compose.e2e.yaml` with a comment (as `RCON_ENCRYPTION_KEY`).
- Run `graphify query "<question>"` before grepping; run `graphify update .` after editing code.
- Use Context7 when unsure about a library API (Stripe Node, `@marsidev/react-turnstile`).
- Order statuses in 4a: `PENDING → PAID`, `PENDING → EXPIRED`, `EXPIRED → PAID` (late success). Nothing else writes `status`.
- `publicId`: 22 URL-safe random characters (128 bits).
- Rate limit `POST /api/orders`: 10 / min per IP, env `RATE_LIMIT_ORDER`.
- Stripe session: `mode: 'payment'`, 30 min expiry, `metadata.orderId`, `customer_email`, automatic payment methods (no `payment_method_types`).

### Rulings against the spec (recorded here, applied in the tasks)

- **Order lines are `{server, slug, quantity}`, not `productId`.** The storefront knows products by server slug + product slug only (`CatalogProduct` has no id); exposing ids would add a public field for no gain. Limits follow the cart: 1–30 lines (`MAX_LINES`), quantity 1–99 (`MAX_QTY`).
- **Turnstile site key is read at request time** (`TURNSTILE_SITE_KEY`, server env, passed from the layout as a prop), not `NEXT_PUBLIC_*`: the web image is built once in CI and deployed with different keys.
- **Product deletion:** `order_items.productId` is `onDelete: Restrict`; `ProductsService.remove` maps the FK error to `inUse({orders: n})`.

## Review Focus

1. A webhook event replayed or delivered concurrently by two API replicas must change the order and send the receipt exactly once — Task 6 has a concurrent-delivery int test.
2. A crafted request body with a price, total or currency mismatch must never reach `PAID` at a different amount — Task 5 ignores client prices (test sends extra `unitAmountMinor` fields), Task 6 checks `amount_total`/`currency`.
3. The fake gateway must be impossible to enable by accident in production — Task 3 test: `NODE_ENV=production` + `PAYMENTS_GATEWAY=fake` without `PAYMENTS_ALLOW_FAKE=true` throws at startup; Task 7 test: the fake page route returns 404 when the Stripe gateway is active.
4. A player who presses Back on the payment page must find the cart intact; a player on a paid status page must end with an empty cart — Task 10 unit test on cookie clearing only on `PAID`; Task 12 e2e asserts the badge.
5. Status page for an unknown or malformed `publicId` must 404, not 500 — Task 5 (API) and Task 10 (web) tests.

```ts
import * as v from 'valibot'

import {CurrencySchema, LocaleSchema} from './catalog'

export const ORDER_STATUSES = [
  'PENDING',
  'PAID',
  'DELIVERED',
  'EXPIRED',
  'REFUNDED',
  'DISPUTED'
] as const
export const OrderStatusSchema = v.picklist(ORDER_STATUSES)
export type OrderStatus = (typeof ORDER_STATUSES)[number]

/** Same caps as the storefront cart (`apps/web/src/config/cart.ts`). */
export const ORDER_MAX_LINES = 30
export const ORDER_MAX_QTY = 99
/** The game server's nickname rule; RCON commands are rendered only from nicks that pass it. */
export const NICK_PATTERN = /^[A-Za-z0-9_]{3,16}$/
export const PUBLIC_ID_PATTERN = /^[A-Za-z0-9_-]{22}$/

const SLUG = /^[a-z0-9-]{1,40}$/
const Minor = v.pipe(v.number(), v.integer(), v.minValue(0))
const Iso = v.pipe(v.string(), v.isoTimestamp())

const OrderLineSchema = v.strictObject({
  server: v.pipe(v.string(), v.regex(SLUG)),
  slug: v.pipe(v.string(), v.regex(SLUG)),
  quantity: v.pipe(v.number(), v.integer(), v.minValue(1), v.maxValue(ORDER_MAX_QTY))
})

export const CreateOrderRequestSchema = v.strictObject({
  lines: v.pipe(
    v.array(OrderLineSchema),
    v.minLength(1),
    v.maxLength(ORDER_MAX_LINES),
    v.check(
      lines => new Set(lines.map(l => `${l.server}/${l.slug}`)).size === lines.length,
      'duplicate line'
    )
  ),
  currency: CurrencySchema,
  locale: LocaleSchema,
  nick: v.pipe(v.string(), v.trim(), v.regex(NICK_PATTERN)),
  email: v.pipe(v.string(), v.trim(), v.maxLength(254), v.email()),
  deliveryConsent: v.literal(true),
  termsAccepted: v.literal(true),
  turnstileToken: v.pipe(v.string(), v.minLength(1), v.maxLength(2048))
})
export type CreateOrderRequest = v.InferOutput<typeof CreateOrderRequestSchema>

export const CreateOrderResponseSchema = v.object({publicId: v.string(), redirectUrl: v.string()})
export type CreateOrderResponse = v.InferOutput<typeof CreateOrderResponseSchema>

export const OrderItemViewSchema = v.object({
  productName: v.string(),
  quantity: v.number(),
  unitAmountMinor: Minor
})
export const OrderServerGroupSchema = v.object({
  serverName: v.string(),
  items: v.array(OrderItemViewSchema)
})

export const PublicOrderSchema = v.object({
  publicId: v.string(),
  status: OrderStatusSchema,
  nick: v.string(),
  email: v.string(),
  currency: CurrencySchema,
  totalMinor: Minor,
  servers: v.array(OrderServerGroupSchema),
  createdAt: Iso,
  paidAt: v.nullable(Iso)
})
export type PublicOrder = v.InferOutput<typeof PublicOrderSchema>

export const AdminOrderListItemSchema = v.object({
  id: v.string(),
  publicId: v.string(),
  createdAt: Iso,
  nick: v.string(),
  email: v.string(),
  currency: CurrencySchema,
  totalMinor: Minor,
  status: OrderStatusSchema
})
export const AdminOrderPageSchema = v.object({
  orders: v.array(AdminOrderListItemSchema),
  nextCursor: v.nullable(v.string())
})
export type AdminOrderPage = v.InferOutput<typeof AdminOrderPageSchema>

export const AdminOrderQuerySchema = v.object({
  q: v.optional(v.pipe(v.string(), v.trim(), v.maxLength(100))),
  status: v.optional(OrderStatusSchema),
  cursor: v.optional(v.pipe(v.string(), v.maxLength(64)))
})
export type AdminOrderQuery = v.InferOutput<typeof AdminOrderQuerySchema>

export const AdminOrderSchema = v.object({
  ...PublicOrderSchema.entries,
  id: v.string(),
  locale: LocaleSchema,
  stripeSessionId: v.nullable(v.string()),
  deliveryConsentAt: Iso,
  subtotalMinor: Minor,
  discountMinor: Minor
})
export type AdminOrder = v.InferOutput<typeof AdminOrderSchema>
```

`payment-events.ts`:

```ts
import type Stripe from 'stripe'

import type {PaymentEvent} from './payments-gateway'

const PAID = new Set(['checkout.session.completed', 'checkout.session.async_payment_succeeded'])
const FAILED = new Set(['checkout.session.expired', 'checkout.session.async_payment_failed'])

/** Stripe event → what the orders module acts on. Card payments complete as `paid`; BLIK/P24 may complete `unpaid` and settle later. */
export function toPaymentEvent(event: Stripe.Event): PaymentEvent {
  const base = {eventId: event.id, type: event.type}
  if (!PAID.has(event.type) && !FAILED.has(event.type)) return {kind: 'ignored', ...base}
  const s = event.data.object as Stripe.Checkout.Session
  const orderId = s.metadata?.orderId ?? null
  if (FAILED.has(event.type)) return {kind: 'failed', ...base, sessionId: s.id, orderId}
  if (s.payment_status !== 'paid') return {kind: 'ignored', ...base}
  return {
    kind: 'paid',
    ...base,
    sessionId: s.id,
    orderId,
    amountTotal: s.amount_total ?? -1,
    currency: (s.currency ?? '').toUpperCase()
  }
}
```

```ts
import Stripe from 'stripe'

import {toPaymentEvent} from './payment-events'
import {InvalidSignatureError, type PaymentsGateway, type SessionRequest} from './payments-gateway'

const SESSION_TTL_S = 30 * 60

export class StripeGateway implements PaymentsGateway {
  readonly name = 'stripe'
  private readonly stripe: Stripe
  constructor(
    secretKey: string,
    private readonly webhookSecret: string
  ) {
    this.stripe = new Stripe(secretKey)
  }

  async createSession(req: SessionRequest) {
    const s = await this.stripe.checkout.sessions.create(
      {
        mode: 'payment',
        customer_email: req.email,
        locale: req.locale,
        metadata: {orderId: req.orderId},
        expires_at: Math.floor(Date.now() / 1000) + SESSION_TTL_S,
        success_url: req.successUrl,
        cancel_url: req.cancelUrl,
        line_items: req.lines.map(l => ({
          quantity: l.quantity,
          price_data: {
            currency: req.currency.toLowerCase(),
            unit_amount: l.unitAmountMinor,
            product_data: {name: l.name}
          }
        }))
      },
      {idempotencyKey: `order-${req.orderId}`}
    )
    if (!s.url) throw new Error('Stripe returned a session without a URL')
    return {sessionId: s.id, url: s.url}
  }

  parseWebhook(rawBody: Buffer, signature: string | undefined) {
    if (!signature) throw new InvalidSignatureError('missing signature')
    try {
      return toPaymentEvent(
        this.stripe.webhooks.constructEvent(rawBody, signature, this.webhookSecret)
      )
    } catch (error) {
      if (error instanceof Stripe.errors.StripeSignatureVerificationError)
        throw new InvalidSignatureError(error.message)
      throw error
    }
  }
}
```

```ts
import {randomBytes} from 'node:crypto'

import Stripe from 'stripe'

import {toPaymentEvent} from './payment-events'
import {InvalidSignatureError, type PaymentsGateway, type SessionRequest} from './payments-gateway'

type FakeSession = SessionRequest & {id: string}

/** e2e only: a "payment page" on the API that signs Stripe-shaped webhooks with the real secret. */
export class FakeGateway implements PaymentsGateway {
  readonly name = 'fake'
  private readonly sessions = new Map<string, FakeSession>()
  constructor(
    private readonly webhookSecret: string,
    private readonly publicOrigin: string
  ) {}

  createSession(req: SessionRequest) {
    const id = `cs_fake_${randomBytes(12).toString('hex')}`
    this.sessions.set(id, {...req, id})
    return Promise.resolve({sessionId: id, url: `${this.publicOrigin}/api/payments/fake/${id}`})
  }

  session(id: string) {
    return this.sessions.get(id)
  }

  signedEvent(id: string, type: 'checkout.session.completed' | 'checkout.session.expired') {
    const s = this.sessions.get(id)
    if (!s) throw new Error(`unknown fake session ${id}`)
    const paid = type === 'checkout.session.completed'
    const payload = JSON.stringify({
      id: `evt_fake_${randomBytes(12).toString('hex')}`,
      object: 'event',
      type,
      data: {
        object: {
          id: s.id,
          object: 'checkout.session',
          metadata: {orderId: s.orderId},
          amount_total: s.lines.reduce((sum, l) => sum + l.unitAmountMinor * l.quantity, 0),
          currency: s.currency.toLowerCase(),
          payment_status: paid ? 'paid' : 'unpaid'
        }
      }
    })
    return {
      body: payload,
      signature: Stripe.webhooks.generateTestHeaderString({payload, secret: this.webhookSecret})
    }
  }

  parseWebhook(rawBody: Buffer, signature: string | undefined) {
    if (!signature) throw new InvalidSignatureError('missing signature')
    try {
      return toPaymentEvent(Stripe.webhooks.constructEvent(rawBody, signature, this.webhookSecret))
    } catch (error) {
      throw new InvalidSignatureError(error instanceof Error ? error.message : 'invalid signature')
    }
  }
}
```

```ts
import {FakeGateway} from './fake-gateway'
import type {PaymentsGateway} from './payments-gateway'
import {StripeGateway} from './stripe-gateway'

/**
 * `PAYMENTS_GATEWAY`: `stripe` or `fake` (default `fake` outside production). Production refuses
 * the fake unless `PAYMENTS_ALLOW_FAKE=true` (the e2e image runs with NODE_ENV=production).

export function createPaymentsGateway(env: Partial<Record<string, string>>): PaymentsGateway {
  const prod = env.NODE_ENV === 'production'
  const kind = env.PAYMENTS_GATEWAY ?? (prod ? undefined : 'fake')
  if (kind === 'stripe') {
    if (!env.STRIPE_SECRET_KEY || !env.STRIPE_WEBHOOK_SECRET)
      throw new Error(
        'STRIPE_SECRET_KEY and STRIPE_WEBHOOK_SECRET must be set for PAYMENTS_GATEWAY=stripe'
      )
    return new StripeGateway(env.STRIPE_SECRET_KEY, env.STRIPE_WEBHOOK_SECRET)
  }
  if (kind === 'fake') {
    if (prod && env.PAYMENTS_ALLOW_FAKE !== 'true')
      throw new Error(
        'PAYMENTS_GATEWAY=fake in production needs PAYMENTS_ALLOW_FAKE=true (e2e only)'
      )
    return new FakeGateway(
      env.STRIPE_WEBHOOK_SECRET ?? 'whsec_local_fake',
      env.PUBLIC_WEB_ORIGIN ?? 'http://shop.localhost'
    )
  }
  throw new Error(`PAYMENTS_GATEWAY must be "stripe" or "fake", got "${String(kind)}"`)
}
```

```ts
const SITEVERIFY = 'https://challenges.cloudflare.com/turnstile/v0/siteverify'
/** Cloudflare's documented always-pass secret; the matching site key is 1x00000000000000000000AA. */
const TEST_SECRET = '1x0000000000000000000000000000000AA'
const TIMEOUT_MS = 5000

export const TURNSTILE = Symbol('TURNSTILE')

export class TurnstileVerifier {
  constructor(
    private readonly secret: string,
    private readonly fetchFn: typeof fetch = fetch
  ) {}

  /** Fails closed: an unreachable Cloudflare blocks orders rather than letting bots through. */
  async verify(token: string, ip: string): Promise<boolean> {
    try {
      const res = await this.fetchFn(SITEVERIFY, {
        method: 'POST',
        headers: {'content-type': 'application/x-www-form-urlencoded'},
        body: new URLSearchParams({secret: this.secret, response: token, remoteip: ip}).toString(),
        signal: AbortSignal.timeout(TIMEOUT_MS)
      })
      if (!res.ok) return false
      return ((await res.json()) as {success?: unknown}).success === true
    } catch {
      return false
    }
  }
}

export function createTurnstile(env: Partial<Record<string, string>>): TurnstileVerifier {
  if (env.TURNSTILE_SECRET_KEY) return new TurnstileVerifier(env.TURNSTILE_SECRET_KEY)
  if (env.NODE_ENV === 'production')
    throw new Error('TURNSTILE_SECRET_KEY must be set in production')
  return new TurnstileVerifier(TEST_SECRET)
}
```

```ts
@AllowAnonymous()
@SkipThrottle({default: true})
@Controller('webhooks')
export class WebhookController {
  constructor(
    @Inject(PAYMENTS_GATEWAY) private readonly gateway: PaymentsGateway,
    private readonly events: PaymentEventsService
  ) {}

  @Post('stripe')
  @HttpCode(200)
  async stripe(
    @Req() req: Request & {rawBody?: Buffer},
    @Headers('stripe-signature') signature?: string
  ) {
    if (!req.rawBody) throw badRequest('invalid_signature')
    let event: PaymentEvent
    try {
      event = this.gateway.parseWebhook(req.rawBody, signature)
    } catch (error) {
      if (error instanceof InvalidSignatureError) throw badRequest('invalid_signature')
      throw error
    }
    await this.events.apply(event)
    return {received: true}
  }
}
```
